VOS DONNÉES

Sauvegarde manuelle

Aucun compte, aucune connexion automatique à Google Drive.

1. Mettre une copie sur Drive

Le fichier de sauvegarde contient les récoltes quotidiennes, le catalogue des produits et tout l'historique depuis 2018.

Sur Android, choisissez Drive dans le menu de partage. Si Drive n'apparaît pas, téléchargez le JSON et importez-le dans Drive manuellement.

2. Restaurer depuis une copie

Récupérez un fichier JSON depuis Drive, puis sélectionnez-le ici.

Attention : la restauration remplace les saisies présentes sur cet appareil. Sauvegardez-les d'abord.

Produits disponibles

Stockage et sécurité

Les saisies sont enregistrées sur cet appareil et restent consultables hors connexion une fois l'application installée. Aucune synchronisation automatique n'est effectuée entre le Pixel et la tablette.

Une réinstallation, l'effacement des données du navigateur ou le changement d'appareil peuvent supprimer les saisies locales : conservez régulièrement un JSON sur Drive. L'application ne demande aucun accès à votre compte Google.
